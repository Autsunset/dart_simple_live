# Simple Live 1.12.4

本版调整抖音的进入方式，并补齐斗鱼的可选账号配置。Android 手机/平板安装包在本机编译、签名后上传，不使用 GitHub Actions 构建。

**这不是“解除斗鱼匿名原画限制”的版本。斗鱼是否返回原画、60 帧取决于平台实际响应；本轮未使用真实登录账号完成原画 1080P60 的端到端验证。**

## 抖音：默认 ttwid 与房间号直进

- 保留内置默认 ttwid，恢复默认配置的设置入口，移除 1.12.3 的内嵌网页登录入口及登录引导。
- 搜索页新增“房间号进入”，链接解析页也提供“抖音房间号进入”。输入数字房间号或支持的直播间完整链接，即可直接打开播放器，不经过关键词搜索。
- 支持输入校验、取消、键盘提交和页面关闭后的回调防护。链接解析遇到空结果时不再读取不存在的首项。
- 主播名、房间名的关键词搜索仍可能受平台限制；直播房间号不等于账号的抖音号，直接进入也不会解除特殊房间的访问限制。

针对用户提供的 `916628331770`，本轮仅使用内置 ttwid、没有登录 Cookie，获取到了房间信息和清晰度，视频请求返回 HTTP 200 及有效 FLV 数据，全程未调用关键词搜索。

## 斗鱼：配置本人 Cookie 后重试

匿名探测中，请求原画 `rate=0`，网页接口实际返回蓝光4M `rate=4`，视频抽样为 1080p、30 fps。全新未登录浏览器在官网选择原画后也出现登录或下载客户端提示。原程序将斗鱼标为“无需登录”且禁用了账号入口，不能传入本人的登录状态。

- “我的 → 账号管理 → 斗鱼直播”现在支持配置本人的完整 Cookie。普通观看继续保留匿名模式，也可以清除配置恢复匿名。
- 播放器的“切换清晰度”中新增配置入口，保存后按当前选择重新请求画质；取消、退出房间或切换房间后不会触发过期的播放操作。
- 配置保存成功后同步到共享播放实例，重启后恢复；保存失败时保留原有配置。Cookie 的登录有效性及原画权限仍由平台判断。
- 读取清晰度时重新签名，避免修改账号/设备状态后使用旧签名。登录 Cookie 不转发给视频 CDN。
- 继续显示服务端实际返回的清晰度，不把降档视频标成原画。
- 哔哩哔哩、抖音、斗鱼账号 Cookie 的新读写日志隐藏值，不改写或删除已经存在的历史日志。

Cookie 是登录凭据，设置备份也可能包含它。请勿把 Cookie、备份文件或配置截图发送给他人。使用说明见 [斗鱼原画与账号状态](douyu-quality.md)。

- 修改的核心代码与测试静态检查通过；App 无错误/警告，仅保留原有 3 条 `onReorder` 弃用提示。
- 三种 ABI release APK 本地构建成功，包名保持 `com.xycz.simple_live`，最低 Android 7.0/API 24，各架构版本码均高于 1.12.3。
- APK 签名、SHA-256、ABI 隔离和 QuickJS 原生库核验通过。生成、合并、strip 和打包的 AOT 产物链已核对；最终 APK 包含新的房间号进入、斗鱼 Cookie 配置和画质重试入口，旧的“网页搜索 / 登录”入口已移除，各架构 AOT 均不同于 1.12.3。
- 签名证书 SHA-256 与上一版一致：`b6bff70c0d93b6c3cf9e621103152c6d0976c3b48ca20aa21493df27f83a2a6f`，可覆盖安装此前本 fork 的同签名版本。

本轮没有完成手机或平板上的账号登录、原画60帧及长期播放验证，不能将匿名接口探测、模拟 Cookie 测试或 APK 构建成功等同于这些验证已通过。

## 本地构建

使用 Flutter 3.44.0 / Dart 3.12.0、Android SDK 36、NDK 28.2.13676358，沿用 1.12.3 的本机签名、Gradle 8.11.1、临时 init 脚本和本地 Maven 缓存映射。`assembleRelease` 离线构建成功，823 项任务中 41 项执行、782 项无需重新执行。

未修改 Gradle Wrapper、Dart 依赖锁、Flutter SDK 或 pub-cache 的源码。现有构建工具后续兼容性提示不属于本版功能变更范围。
