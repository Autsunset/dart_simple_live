# Simple Live 1.12.6

本版合并两项修复：插件 Cookie 复制后无法保存，以及直播断流被误判为未开播。Android 手机/平板安装包在本机构建、签名并上传，不使用 GitHub Actions 构建。

## Cookie 粘贴与 TXT 导入

- 修复 Netscape Cookie 导出内容中的 Tab 被复制过程转换为空格后，保存校验拒绝输入的问题。
- 兼容 Tab、单个空格、多个空格及部分分隔符被转换为空格的记录；直接粘贴和导入 `cookies.txt` 使用同一解析逻辑。
- 保留 Cookie 值的原始编码、域名、路径、Secure、HttpOnly 和到期时间处理；不以放宽登录校验的方式绕过格式错误。
- 保留普通 `name=value; ...` 请求头、抖音单独 ttwid、清除配置等原有输入方式。

在“我的 → 账号管理”选择对应平台后，粘贴插件导出内容或导入原始 TXT 文件，再点击保存即可。斗鱼与抖音的 Cookie 不能混用。

Cookie 含登录凭据，请勿公开分享。格式解析成功不等于登录凭据仍有效，也不保证获得斗鱼原画或 60 帧权限。

## 断流恢复与直播状态

原逻辑在播放器报告播放结束、旧线路重试耗尽后，直接把房间标记为未开播，没有向平台确认。

- 旧线路重试失败后重新读取房间状态；仍在直播或轮播录像时，刷新清晰度与播放地址并重连，优先保留所选清晰度。
- 只有房间接口明确返回非直播且非录像时才显示“未开播”。网络超时、接口异常、播放地址失效或原生播放器打开失败不再直接判定下播。
- 自动重新取流最多两轮，接口请求设有超时；失败后显示“播放中断，自动重连失败，请刷新重试”，并提供刷新按钮。
- 播放进度稳定推进 30 秒后重置重试次数，而不是仅凭播放器打开成功就重置，避免反复断流时无限重连。
- 手动刷新、切清晰度、切线路、换房间或退出会使旧重连结果失效；同一次故障的错误与结束事件继续合并处理。
- 斗鱼状态兼容数字和字符串表示；缺失或无效状态作为读取失败处理，不再默认为下播。

参考了 [June6699 分支 issue #128](https://github.com/June6699/dart_simple_live/issues/128) 及其 [2026-10-02 的断流修复提交](https://github.com/June6699/dart_simple_live/commit/3afc161522eb4861d900aa0050aa2f0bcd1c1b63)。本版没有整体合并该分支的其他功能，也没有采用“重试失败即下播”的处理方式。

## 验证与限制

- App 全量回归 83 项、核心离线回归 65 项通过。
- 覆盖 Cookie 粘贴、TXT 导入、保存与重启恢复，以及提前结束、真正下播、录像、超时、取流失败、原生打开异常、重试上限和过期请求隔离。
- 覆盖“未知状态 / 播放中断 / 未开播”界面提示及刷新按钮。
- 修改的核心代码与测试静态检查通过；App 全量检查没有错误或警告，仅保留原有 3 条 `onReorder` 弃用提示。
- 三种 ABI release APK 构建成功，签名、版本、ABI 隔离、QuickJS 原生库、AOT 产物链及 SHA-256 校验通过。最终 APK 包含两项修复的代码，各架构 AOT 均与 1.12.5 不同。
- 自动化测试使用虚构 Cookie，没有把用户真实凭据写入源码、测试或安装包。

本轮未完成手机/平板真机的长期观看验证，也未使用真实账号验证登录权限。自动重连无法保证恢复所有平台限制或持续网络故障；本版解决的是已确认的格式兼容和下播误判代码路径。
