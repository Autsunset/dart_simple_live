# 斗鱼原画与账号状态

## 为什么显示“实际：蓝光4M”

这个标签表示请求的清晰度与平台实际返回的档位不同，不是播放器把原画缩放成了低画质。

匿名在线探测中，对房间 `6979222`、`252140` 请求原画 `rate=0`，网页播放接口返回 `rate=4`；抽样视频轨道为 1920×1080、30 fps。换用新网页接口也没有恢复原画。在全新的未登录浏览器中，官网选择原画后出现了登录或下载客户端的提示。因此不能把匿名模式下的降档简单归因于某一个房间，也不能通过修改显示文字恢复原画。

## 配置本人登录状态

1. 在浏览器打开斗鱼官网并登录你自己的账号。
2. 从浏览器开发者工具的网络请求头中复制完整的 `Cookie` 值，包含 `acf_did`，不是只复制设备 ID，也不是网址。
3. 在 App 的“我的 → 账号管理 → 斗鱼直播”中粘贴并保存。
4. 返回直播间重新选择清晰度或刷新。也可从播放器的“切换清晰度 → 原画受限？配置斗鱼 Cookie”进入，保存后会自动重新请求当前选择的清晰度。

配置保存在应用设置中，重启后恢复。需要撤销时，在配置弹窗中点击“清除 Cookie，恢复匿名”并保存。普通匿名观看仍然保留，不要求所有用户配置账号。

## 验证边界

- “已配置 Cookie”只表示已保存配置，不等于已验证登录成功或已获得原画权限。
- 签名、设备 ID 和 API 请求使用当前配置；修改配置后不继续沿用旧的签名。登录 Cookie 不转发给视频 CDN。
- 程序继续显示服务端返回的真实清晰度。Cookie 过期、额外验证、房间权限等仍可能导致降档。
- 自动化测试验证保存、重启恢复、清除、失败时保留旧配置、取消弹窗、切房/退出后的回调防护及重新请求当前清晰度；没有使用真实登录账号完成原画 1080P60 的端到端验证，不能宣称匿名原画限制已被解除。

## 凭据安全

Cookie 属于登录凭据，只应在本机 App 中填写，不要发给他人。设置备份也可能包含 Cookie，请勿公开分享备份文件或配置截图。

账号 Cookie 的新读写日志会隐藏值；已经存在的历史日志不会被自动改写或删除。
