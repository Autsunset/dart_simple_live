# Simple Live 1.12.3

本版修复抖音搜索的错误处理、房间号查询和登录入口。Android 手机/平板安装包全部在本机编译、签名后上传，不使用 GitHub Actions 构建。

## 抖音搜索

- 正确识别接口的 `2483` 登录要求，不再把“请先登录”误显示为没有搜索结果。空响应、验证页面和异常数据也会给出可操作的提示。
- 纯数字直播房间号、`live.douyin.com` 直播间完整链接和 `webcast.amemv.com/webcast/reflow/` 直播分享链接直接查询房间，不依赖关键词搜索接口。抖音账号的“抖音号”不等于直播房间号。
- 接通“主播”搜索，使用直播搜索匹配的主播信息，保留头像及直播状态；这不是全量用户搜索，不能保证搜到未开播主播。
- 搜索页提供“网页搜索 / 登录”和“配置 Cookie”。Android 网页入口打开当前关键词对应的抖音官网页面，支持登录后保存登录状态并重试搜索，以及点击直播间返回 App 播放。
- 完整 Cookie 不再被错误添加 `ttwid=` 前缀；仍兼容单独的 ttwid 值，并支持修改或清除现有配置。登录搜索不再依赖额外的匿名 HEAD 请求。

本版不绕过抖音的登录或验证要求。仅有 ttwid 不代表已登录，完整 Cookie 也不保证能通过平台的所有验证。

## 使用方法

1. 在搜索页选择抖音，输入主播名或房间名。
2. 如提示需要登录，点击“网页搜索 / 登录”，在抖音官网完成登录，再点击“保存登录”。
3. App 返回搜索页并重试。也可直接在搜索框粘贴直播房间号或支持的完整链接。

Cookie 包含登录凭据，保存在应用设置中，并可能随设置备份导出。请勿分享 Cookie 或备份文件，也不要把它们贴到公开反馈中。

## 本地构建记录

使用 Flutter 3.44.0 / Dart 3.12.0、Android SDK 36、NDK 28.2.13676358 及本机已有签名配置。

Gradle Wrapper 发行包下载较慢，本轮改用本机缓存的 Gradle 8.11.1 执行 `:app:assembleRelease`，启用三种目标架构和 `split-per-abi`。通过临时 init 脚本和从现有 Gradle 缓存建立的本地 Maven 映射离线解析依赖；第三方插件的构建 classpath 使用缓存中的 AGP 8.9.1、Kotlin Gradle Plugin 2.2.20 和 kotlin-reflect 2.1.20。最终构建成功，823 项任务中 647 项执行、176 项无需重新执行。

未修改仓库的 Gradle Wrapper、Dart 依赖锁、Flutter SDK 或 pub-cache 的源码；临时构建映射不纳入仓库。现有 Gradle/AGP/Kotlin 后续兼容性提示不属于本次搜索修复范围。
