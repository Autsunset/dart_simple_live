# Simple Live 1.12.1

在 [1.12.0](release-1.12.0.md) 的稳定性、分类与聊天性能修复基础上，继续移植原项目开放 PR 的有用改动，并处理安装验证发现的问题。Android 手机/平板安装包与本 fork 上一版使用相同签名。

## 观看历史快捷切换

参考 [上游 PR #881](https://github.com/xiaoyaocz/dart_simple_live/pull/881)，播放画面长按弹窗新增「关注列表 / 观看历史」。普通播放、全屏、竖屏底部弹窗和横屏侧栏共用一个组件，在当前播放会话中记住上次选择，显示当前观看标记、平台和观看时间，点击即可切台。

历史列表每次打开只读取、排序一次，使用懒加载列表；过滤不支持的平台，空关注列表可下拉刷新。切换平台时重建聊天标签，避免从 B站切到斗鱼后保留 SC 标签；立即清除旧清晰度、线路、头像信息和开播时长，取消旧时长计时，恢复聊天跟随。

## 定时关闭

此前倒计时到期后，10秒退出定时器仅存放在回调局部变量中，离开直播间或关闭定时功能无法取消；迟到的确认结果也可能继续退出应用。本版保存并取消该定时器，用请求代次隔离旧确认，在异步关闭屏幕常亮后再次检查当前状态，确保超时与弹窗结果最多执行一次退出。

回归使用受控退出回调验证行为，测试进程不会真的退出。

## 斗鱼画质排查与改进

本轮使用同一房间 `6979222`、同一签名/设备身份，对比 API 参数和 ffprobe 视频轨道：

| 请求组合 | 返回 rate / 轨道 | 实际视频 |
| --- | --- | --- |
| `iar=1, ive=1, fa=0` | rate=2，视频+音频 | 960×540，25 fps |
| `iar=0, ive=0, fa=0` | rate=4，视频+音频 | 1920×1080，30 fps |
| `fa=1` | rate=0，只有 AAC 音频 | 没有视频轨道，不能作为原画视频方案 |

同一房间两个 CDN 得到一致结果；房间 `252140` 的新版调用也确认 1920×1080、30 fps。

本版关闭自适应降档参数，保持 `fa=0` 获取视频。保留请求的 rate，优先选择真正返回所选 rate 的 CDN，同时保留其他可用线路。核心返回每条线路的实际清晰度名称，App 切换线路后同步显示，降档时显示「实际：蓝光4M」等名称。

签名和 API Cookie 使用一致设备身份，匿名请求使用进程内随机身份，SDK 也可注入 deviceId 或 Cookie；不再让所有调用共用写死的假 did。播放 CDN 仅接收 Referer/User-Agent，不转发账号 Cookie。签名参数通过 JSON 编码进入 JS，避免引号/反斜杠被当作代码。

这解决了可复现的自适应降档和清晰度显示失真，**没有证明匿名原画 60 fps 已恢复**。服务端本轮仍会覆盖请求的高档 rate。[反馈 #138](https://github.com/June6699/dart_simple_live/issues/138) 中 `63136` 的房间接口可访问，`6657` 返回提示页面；不能将其他房间的成功等同于该反馈完全解决。

## 验证

- App 23项回归通过，覆盖已有稳定性测试及历史切换/记忆/刷新/关闭、平台标签重建、旧播放数据清理、定时关闭竞态、实际清晰度随线路变化。
- 核心离线19项回归通过，新增正确清晰度线路优先、每条线路质量名称、Cookie设备身份、实际 JS 签名输入编码验证。
- 斗鱼在线9项测试通过，包含分类、推荐、搜索、详情、清晰度、线路及30秒弹幕；ffprobe 视频结果见上表。
- 核心静态检查通过；App 无错误/警告，仅原有3条 `onReorder` 弃用提示。
- 三种 ABI release 构建、APK签名和 SHA-256 校验通过。最低 Android 7.0/API 24。另检查 Flutter 原始字节码确认两个被变换的方法仍由 `maybeWaitOnFence` 的 API>=33 条件保护，未因回补引入旧 Android 的 SyncFence 调用。
- Android 16 / x86_64 容器：已确认竖屏底部弹窗、横屏历史侧栏、当前观看标记、历史切台、未开播状态，以及从 B站切到斗鱼后只剩3个聊天标签。最终包4分钟、每30秒一次采样，涵盖持续播放和两次后台/恢复，PID 始终为39872，FD 165–196、sync_file 13–37，未新增进程崩溃退出原因。本轮容器还确认了B站与虎牙实际画面及弹幕；是有限时长验证。

与 1.12.0 一样，本轮没有小米平板 5 Pro 长期真机测试；之前出现过的 AMD/Mesa 容器驱动崩溃未被本版宣称修复。原项目关闭 issue 功能，九个开放 PR 的审查与取舍记录仍见 1.12.0；新增采用 #881，不整体导入其重复组件实现。
