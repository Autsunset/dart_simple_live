# Simple Live 1.12.5

本版为斗鱼和抖音增加 Netscape Cookie 文件导入。安装包在本机编译、签名并上传，不使用 GitHub Actions 构建。

**本版修复的是 Cookie 输入格式兼容性，不代表斗鱼原画或登录鉴权问题已经解决。文件解析、导入成功与平台接受登录状态是两回事。**

## 使用方法

1. 在浏览器插件中为对应平台导出 Netscape 格式的 `cookies.txt`。
2. 打开“我的 → 账号管理”，选择斗鱼或抖音。
3. 点击“导入 cookies.txt”，或者直接把完整文件内容粘贴到输入框。
4. 点击保存。通过斗鱼播放器清晰度菜单进入配置时，保存后会重试当前清晰度。

不需要手动删除文件头、拼接分号、解码认证字段或修改 Cookie 值。原有 `name=value; ...` 请求头输入、单独输入抖音 ttwid、恢复默认 ttwid 和抖音房间号直进继续保留。

斗鱼对应 `.douyu.com`、`www.douyu.com`；抖音对应 `.douyin.com`、`live.douyin.com`。不要把两个平台的文件混填。

## 处理规则

- 支持七列 Tab 分隔记录、UTF-8 BOM、CRLF 换行、注释、`#HttpOnly_` 记录和空值。文件大小限制为 2 MiB。
- 保留 Cookie 的域名、子域标记、路径、Secure 和到期时间属性，Cookie 值不进行 URL 解码或重新编码，保留 `%2F`、`+`、`=` 等原始内容。
- 多站点文件只保存所选平台的记录；过期项会被忽略，到期时间为 `0` 的会话 Cookie 不会被误判为过期。
- 每次请求根据实际 URL 的域名、路径、协议和当前时间生成请求头，不把七列表格直接发送给接口。保留同名但不同作用域的 Cookie；同一作用域的重复项采用最后一条。
- 错平台、无适用记录、全已过期、格式损坏、文件读取失败或取消导入不会覆盖现有配置。关闭窗口后返回的文件选择结果不会更新已销毁的编辑器。
- 抖音请求头使用独立快照，避免并发请求相互覆盖 Cookie；弹幕参数的诊断文本不再输出 Cookie 值。

导入不会改写用户的原始文件。文件内容和 Cookie 都包含敏感登录凭据，设置备份也可能包含它们，请勿公开分享。详细说明见 [斗鱼原画与账号状态](douyu-quality.md)。

## 验证

- App 全量回归 61 项、核心离线回归 56 项通过。
- 覆盖值编码保留、域名与路径匹配、Secure/HttpOnly、会话 Cookie、过期筛选、同名不同作用域、BOM/CRLF、空值、超大/损坏文件、导入取消、配置持久化、保存失败回退、错误信息不暴露凭据、真实签名设备 ID 选择及 HTTP 请求头转换。
- 静态检查没有新增错误或警告；App 保留原有 3 条 `onReorder` 弃用提示。
- 匿名在线烟测继续确认默认 ttwid 和房间号直进可用，获得有效 FLV 数据。Netscape 自动化测试使用虚构数据，没有把用户提供的真实登录凭据写入源码、测试文件或安装包。
- 三种 ABI release APK 本机构建成功。签名、版本码、ABI 隔离、QuickJS 原生库、AOT 产物链和 SHA-256 校验通过；最终 APK 包含新的文件导入与格式校验代码，AOT 与 1.12.4 不同。
- 未完成手机/平板系统文件选择器的真机验证，也未验证真实账号导入后恢复斗鱼原画60帧。取流协议改造不包含在本版中。
